XANDRIA Live

Prompt-to-game engine. You describe a game in plain language and get a playable game back. Generation is deterministic and seeded, and every output runs through a validated GameSpec pipeline before it ships.

Five genres: third-person action, FPS arena, racing, platformer, and top-down shooter. Worlds go up to 8000m. NPC, enemy, crafting, and portal waves have shipped, and a continuous upgrade loop keeps shipping new waves on branches for review. SaaS tiers: Free (5 generations/mo), Hobby $12/mo, Pro $39/mo, billed through Stripe. The itch.io edition splits into a free demo (2 genres, no export) and a full edition at $10+ PWYW (all 5 genres, HTML export).

Stack: TypeScript, Three.js, cannon-es, Vite

Live app · itch.io · GitHub

KeelCode Complete

Standalone game engine built around one framework spec and three backends, so the same game logic can run in different runtimes without a rewrite.

Backends: a TypeScript/Three.js reference implementation, a Rust headless simulation with wgpu, and Babylon with Havok physics. The keel CLI is the primary interface. All five build waves are merged, including STARFALL: Drift Arena, a 3D vertical slice built on the TypeScript backend. Local repo only; there is no public link.

Stack: TypeScript, Three.js, Rust, wgpu, Babylon, Havok

Local only

STARFALL In Progress

Open-world top-down 2D space shooter for mobile and desktop, with nine ship classes from fighter to mothership.

The v2 sprite expansion generated 137 sprites across factions, celestial bodies, and FX. Wired in game: player ships, faction ships (enemies), celestial bodies (planets, moons, asteroids, fields, and biomes), and stations all render the v2 art. Not wired yet: the FX set proper, meaning projectiles, explosions, powerup icons, turrets, mines and drones, and collectibles. Rendering for those is still procedural.

Stack: JavaScript, Canvas

Local build

DUSKFALL In Progress

Open-world action RPG with PS2 and GTA-III-era textured low-poly graphics. All textures are procedural; there are no external assets.

Version 1 scope is one docks district on foot: third-person movement, gang and cop AI, wanted stars, a quest chain of 3 or more missions, dialogue, XP, a GTA-style HUD, and a localStorage save. Drivable cars are out of v1 by design. Graphics Wave 4 is complete: MeshStandardMaterial with procedural roughness and normal maps, an EffectComposer post chain (bloom on desktop, FXAA on both tiers), PCF soft sun shadows on desktop, and planar water reflection on desktop.

Caveat: frame rate cannot be measured honestly in the sandbox (software rendering). The targets, 60 fps on desktop and 30 fps on mobile (Galaxy S25), still need a real-device pass.

Stack: TypeScript, Three.js, Vite

Local build

Halcyon Expanse (2D + 3D) Shipped

One universe, two builds. The 2D version is a top-down RPG in Python with combat, branching dialogue, progression, inventory, and quests. The 3D version rebuilds the same world in Godot 4.3 with GDScript, camera-relative movement, 3D physics, spatial audio, and dynamic lighting.

Together they test a simple claim: the same game design can target two engines and two dimensions without losing its systems.

Stack: Python; Godot 4.3, GDScript

RGH — Reality Grounding Harness In Progress

Four-chamber falsification pipeline for framework claims. Chamber 1 is an external measurement gate. Chamber 2 is a falsifiability stress test. Chamber 3 is independent replication with no shared state. Chamber 4 is a domain-crossing consistency audit.

If a claim survives all four, it is grounded for now. If not, it gets flagged with specific failure modes. I run my own frameworks through it first, and when the harness itself was found broken, the breakage was reported before the fix.

Stack: Python

GitHub · Philosophy: The Method

URCS v1.0 Shipped

Universal Reversion and Containment Standard v1.0. A hardware-anchored kill-switch architecture for autonomous systems, designed for reversion in under 300ms after anomalous behavior is detected.

Unlike software-only safety layers, containment is anchored in physical hardware states. The standard defines behavioral monitoring, containment boundaries, graceful degradation, and irreversible shutdown sequences.

Stack: Architecture, safety standard

Aetheric Resonance Surveyor (ARS) Pre-registered

Multi-channel anomaly-signal monitoring instrument. It watches multiple channels under a standing watch that reports only genuine Tier-1 flags. Silence is the default.

Two additions landed in October 2026: a provenance cross-check (radio and harmonic captures are checked against the broadcaster-declared now-playing title, so a mundane human origin is corroborated or marked unaccounted instead of assumed) and a transient registry (structured transients the gates discard are kept, and recurrences across days are reported as prompts for a human look, never as detections).

The beacon experiment v1 is pre-registered: 1 baseline plus 5 transmission trials, blinded analysis, pre-committed hash. Status: instrument live, experiment pre-registered and awaiting trials. By the standing identification rule, a signal counts as man-made only when its human origin is confirmed, not merely pattern-matched.

Stack: Python
